# Doctor headshots

Upload one photo per doctor, then set each `photoUrl` in `js/config.js`.

| File to upload | Doctor | Config key |
| --- | --- | --- |
| `nadyne-reyes.jpg` | Dra. Nadyne Reyes | `dentists[0].photoUrl` |
| `jessica-flores.jpg` | Dra. Jessica Flores | `dentists[1].photoUrl` |
| `florencia-andino.jpg` | Dra. Florencia Andino | `dentists[2].photoUrl` |
| `zury-flores.jpg` | Dra. Zury Flores | `dentists[3].photoUrl` |

Recommended: square or portrait JPG, at least **800×800 px**.

**Upload on GitHub:**  
https://github.com/stellier7/Clinica-Dental-Adanze/upload/main/assets/images/dentists

After uploading, update each entry in `js/config.js`, for example:

```js
photoUrl: "assets/images/dentists/nadyne-reyes.jpg",
```
